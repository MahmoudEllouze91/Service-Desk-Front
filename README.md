# Service-Desk-Front
A simple frontend application to train myself with React. Functionally, the application will allow to create and see demands and interact with them as a user, operator, and responsable.

## Requirements

- Node.js
- npm

## Installation

Download the project trough Github with this command
```sh
git clone https://github.com/MahmoudEllouze91/Service-Desk-Front.git
```

Go to the root path of the project and run this command to install the packages of the application
```sh
npm install
```

After the package installation run this command.
```sh
npm run dev
```
The serviceDesk application will bee available on the local URL http://localhost:5173/
